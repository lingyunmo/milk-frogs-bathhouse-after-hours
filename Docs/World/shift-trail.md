# 七月十七日交班记录

本文含《奶娃浴场：打烊后》的剧情谜底。七项工单各有一处签收点；手头工单、部分维修、调查证物和证词去向均随单人存档保留。

| 玩家在哪里发现事情 | 要动手做什么 | 做完后世界里发生什么 |
| --- | --- | --- |
| 二楼更衣室 | 取手电，循白布结找到钥匙，开毛巾库 | 钢架上才出现第一笔可签的交班记录 |

## 名单漏掉的人

八七年汛期，堤上十二人住进临时洗衣棚。一名临时洗衣工也在水里接人。她借来庙会的黄布头套和黑手套，连笑三声，让看不清岸的孩子朝她游。床位登记只收安置户，收洗联却多了一条打结的小毛巾。两年后，十二家人在洗衣棚办起公共浴场，第一池热水空放给值夜的人。

玩家必须亲自核对收洗数、复原旧址和辨认接应板。走到这里，可以证明名单少记了一人。她的姓名、浴场为什么开在此地、笑声为何只在闭店后响，分别藏在借衣簿、第一号浴票和试音记录里。夜闸合上会使旧管线和广播共振，但记录里也有人在断线后听过笑声。游戏让这两条证词并存。

## 同一辆末班车

| 从哪里分岔 | 玩家做了什么 | 登车结果 |
| --- | --- | --- |
| 必经调查结束 | 带走合影，没找到守闸人的借衣簿 | 「末班乘客」，车票留下水印，照片里仍多出一个没有名字的人 |
| 守闸宿舍 | 从棉被里找到了袁素琴的名字，保留在身上 | 「未寄出的名字」，借衣簿和车票一起带出浴场 |
| 取得姓名与合影后，回主楼弱电间 | 长按播报实名 | 「有人应名」，车载电台念名，车窗收到回答 |
| 取得姓名与合影后，在守闸宿舍 | 长按封存原片，交给早班 | 「请日班亲启」，司机签收留给日班的证物 |

播报和封存只能选一项。读书、捡照片或开工单不会替玩家做决定。带走浴票或试音记录还会改变结尾的一个细节。第五夜被抓仍是失败结局。

## 末班车票夹

标题画面右上角可以翻开票夹。每次真正登车或在第五夜失手，才盖上这一张票的验讫章。开新局时保留历次收集。以前的版本只留一份单局存档，更新后读取到的已结束存档会补记对应结局。票夹收四张原有登车票、一张末夜票，以及一张封着的票。

同局办完七张工单、校正站牌，完成两条排水路和三条联络路、正备用接应信号，收下前台空投、值班补给，试过货门铃与配平后的堤外警铃，读故障单、收洗联、浴票、借衣簿、关门试音记录，并选定证物去向。播报名单和封存底片各自是不可撤回的叙事选择，任选其一。电池、石子等重复耗材没有收集配额。

普通工单依旧在第一条有效维修路线完成时办结。玩家可以在两张工单的空档补验同一设备的其他线路。路面准备就绪后，值班箱、货门铃、备用接应灯能在当夜复查。第二种接应方式只验线路，已经赶来的车照常到站。旧档若只记载「联络过」而没有记录具体线路，三处现场都可以重新通话。

所有条件在同一局成立时，水塔背后的旧票务所开闸。玩家仍可开普通结局。五间房共用一排钢闸，每完成一间才打开下一道；退回原路与跨夜续玩都保留手里的票根。

| 房间 | 动手查证 | 带到下一间的东西 |
| --- | --- | --- |
| 留根间 | 自己任选左、中、右一个孔打票 | 只属于这一局的半张票 |
| 熨印间 | 墨面朝下，用镜架找相反的孔位 | 票背甲路或乙路水印 |
| 监听间 | 接听三根管道，按来声次序逐根敲回。灯与字幕同步提示 | 与所选孔位对应的三声回响 |
| 气封间 | 抱起铜筒、走到墙边泄压、按水印选择投递口 | 消失在封闭管道里的另一联票 |
| 签收间 | 掀铅封，把自己的票根与落地联叠孔，再拿起话筒回答 | 八七年的签收戳、玩家亲自选择的骑缝孔与袁素琴的交班签名 |

八七年，人和洪水都是真实的。十二个孩子上了车，袁素琴本来也能随车离开。她听到的第十三个求救声来自几十年后正在喊车的玩家。十二家人把棚改作浴场，留下双管，等的是一声回话。白天两路分开；打烊泄压，两晚的末班车接在了一起。走廊里的黄皮一直循着尚未被接走的求救者。最后一间才给玩家一件可检验的证据：刚选的孔位出现在八七年的原联上，还能听见本局第一次联络司机的声音从过去传回。回复老线，袁素琴便能上车，追逐停止。玩家仍从原站牌登车，这时才盖上隐藏票。
